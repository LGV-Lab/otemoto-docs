Otemoto プライバシーポリシー

最終更新日: 2026年11月25日

Otemoto（以下「本アプリ」）は、LGV Lab が提供する iPad / iPhone 向けリモートデスクトップクライアントです。 本アプリはユーザーのプライバシーを最大限に尊重し、以下のとおり個人情報およびデータの取り扱い方針を定めます。

1. 収集する情報について

本アプリの開発者（LGV Lab）は、ユーザーの氏名・メールアドレス・位置情報・利用履歴・操作画面・入力文字・転送ファイル・接続先アドレス等の個人データを 一切収集・送信・第三者提供しません。また、広告 SDK や外部アナリティクスツールも組み込んでいません。

2. 端末内および iCloud に保存される情報

本アプリは以下の設定データをユーザーの端末内（およびユーザーが iCloud 同期を有効にした場合はユーザー自身のプライベート iCloud 領域）にのみ保存します。

  • 登録した接続先コンピュータ名・ホスト名・ポート番号・表示設定
  • 接続用パスワード・SSH 秘密鍵・任意設定の Tailscale API 認証情報（Apple の Keychain に暗号化して保存）
  • カスタムショートカットデッキの設定・お気に入りフォルダ・SSH ユーザー名
  • 他アプリから共有シート経由で一時的に受け渡したファイル（送信完了後または一定時間後に削除されます）

設定画面の「プライバシーとバックアップ › 全内容と設定を消去」から、これらのデータをいつでも一括削除できます。

3. ネットワーク通信について

本アプリは以下の目的でのみネットワーク通信を行います。

  • ユーザーが指定したリモートコンピュータ（Mac / PC）への直接接続（画面共有 / VNC / SSH / SFTP）
  • 同一ローカルネットワーク内の接続可能コンピュータの検出（Bonjour）
  • App Store でのアプリ内課金（StoreKit 2）の購入・復元処理
  • ユーザーが任意で Tailscale API 連携を設定した場合の Tailscale サーバーとの通信

4. 外部サービス（Tailscale 等）について

外出先からの接続に公式 Tailscale アプリ等を利用される場合、当該サービスにおけるデータの取り扱いは各提供元のプライバシーポリシーに従います。 上級者向けの Tailscale API 連携を任意で設定した場合を除き、本アプリが Tailscale のアカウント情報や認証情報を取得・保存することはありません。

5. お問い合わせ

本ポリシーに関するお問い合わせは、Otemoto サポートページ または GitHub Issues よりご連絡ください。
